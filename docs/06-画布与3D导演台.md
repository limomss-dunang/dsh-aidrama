# 画布与 3D 导演台

## 目标

在「短剧」工作台里增加两个阶段：

- **画布**：把角色、场景、道具、分镜和 3D 导演台节点放在同一张无限画布上，支持缩放/平移、拖动、连线、备注和整理布局。
- **3D导演台**：用灰盒人偶、道具和机位快速排站位与镜头，右侧实时机位预览；截图可直接发送回画布，形成构图参考节点。

## 现成方案与调研结论

没有直接嵌入某个完整的「短剧 3D 导演台」开源项目，原因是现有项目大多是 Electron/桌面应用或绑定自研资产格式，直接搬进来成本高于收益。因此采用现成的底层能力，按小云雀的交互模型接入：

| 能力 | 采用的现成项目 | 用途 |
| --- | --- | --- |
| 3D 渲染、相机、光照 | [three.js](https://github.com/mrdoob/three.js) | 3D 视窗、机位预览、截图 |
| 轨道控制 | `three/examples/jsm/controls/OrbitControls.js` | 左键旋转、滚轮缩放、右键平移 |
| 对象变换 | `three/examples/jsm/controls/TransformControls.js` | 移动/旋转/缩放选中对象 |
| 无限画布缩放平移 | [react-zoom-pan-pinch](https://github.com/BetterTyped/react-zoom-pan-pinch) | 画布缩放、平移、适配 |
| 3D 分镜交互参考 | [小云雀 3D 导演台手册](https://www.xiaoyunque.com/tutorials/short-drama-agent-3d-director) | 对象列表、机位预览、截图回画布、构图参考 |
| 3D 预演交互参考 | [Storyboarder Shot Generator](https://github.com/wonderunit/shot-generator-models) | 人偶/道具/机位摆放的分镜预演思路 |

本实现没有复制 Storyboarder 的 Electron 代码和模型资产；复用它的交互思路，底层与它同类（three.js）。

## 已实现

### 画布

- 阶段入口：`短片工作台 → 画布`，侧边栏阶段计数显示 `∞`。
- 自动把当前项目的角色/场景/道具/分镜排成节点；额外有一个「3D 导演台」节点。
- 支持：
  - 缩放、平移；
  - 拖动节点；
  - 点「连线」后点两个节点建立有向连接；
  - 添加/编辑备注；
  - 「整理」按资产列重排；
  - 「重置布局」恢复默认；
  - 删除选中节点。
- 节点数据保存到浏览器本地：
  `dsh-aidrama:canvas:<projectId>`
- 3D 导演台节点上的「打开导演台」直接切到 `3D导演台` 阶段。

### 3D 导演台

- 阶段入口：`短片工作台 → 3D导演台`，侧边栏计数显示 `3D`。
- 左侧：
  - 对象列表（选中、删除）；
  - 加入角色；
  - 加入道具；
  - 添加基础几何体；
  - 重置导演台。
- 中间：
  - three.js 灰盒场景；
  - 角色人偶、道具方块、地面网格；
  - 选中对象用 TransformControls 移动/旋转/缩放；
  - 机位预设：正面、侧面、俯拍、过肩；
  - 当前视角建机位；
  - 实时机位预览小窗；
  - 截图下载；
  - **发送到画布**：把当前机位截图作为 `shot` 节点写入画布。
- 右侧：
  - 分镜绑定下拉；
  - FOV 调整；
  - 选中对象位置/旋转属性；
  - 删除对象。

保存键：

```text
dsh-aidrama:director:<projectId>
```

## 当前边界

这是静态构图/机位预演 MVP，不包含小云雀的以下高级能力：

- 人体骨骼姿势与动作库；
- 时间轴关键帧、动作/运镜播放；
- 3D 轨迹绘制；
- GLB/GLTF 模型上传与 150+ 道具库；
- 720° 全景背景；
- 动态参考视频导出。

这些能力需要模型资产库和动画状态机，不能靠单个 three.js 场景硬堆；后续可以按「先静态、后动态」顺序继续：

1. 骨骼人偶 + 姿势预设；
2. 关键帧时间轴；
3. 轨迹绘制；
4. 全景背景；
5. 动态参考导出。

## 后续实现进展

在最初 MVP 基础上已补：

- 画布：角色 LOOK 独立节点、场景变体节点、分镜首帧节点、分组框、左右连接口、资产类型筛选、`@` 引用复制、Ctrl/Cmd+C/V、全屏、快捷键面板、小地图、吸附。
- 3D：完整机位预设、机位关键帧、运镜预设（固定/前推/后拉/左摇/右摇/上升/环绕）、场景背景色/地面/主光、动作预设（站立/行走/奔跑/坐下/跪下/挥手/挥拳/倒地/转身）、轨迹绘制并应用到角色、撤销/重做、截图/录屏发送到画布。
- 持久化：`canvas` / `director` 随 `project.json` 保存，旧 localStorage 自动迁移。
